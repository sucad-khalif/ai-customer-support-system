
# AI Customer Support System – Frontend

This directory contains the React-based frontend for the AI Customer Support & Human Handoff System.

## Overview

The frontend provides a web interface for customers and support staff to interact with the platform.

## Main Features

- Customer registration and login.
- Customer dashboard.
- Food order placement.
- Order tracking and order history.
- AI-powered customer support chat.
- Staff dashboard.
- Customer and order management.
- Conversation and human handoff management.

## Technology Stack

- React
- Vite
- React Router DOM
- JavaScript
- CSS

## Installation

From this directory, install dependencies:

```bash
npm install
```

## Development

Start the development server:

```bash
npm run dev
```

## Production Build

Build the frontend:

```bash
npm run build
```

The production build will be generated in the `dist/` directory.

## Backend Connection

The frontend communicates with the FastAPI backend running locally at:

```text
http://127.0.0.1:8000
```

See the root project README for complete backend and database setup instructions.
