# AI Customer Support & Human Handoff System

An AI-powered customer support system that helps businesses automatically answer customer questions, retrieve relevant information from a company knowledge base, and hand over complex or unresolved issues to human support staff.

## Project Overview

The system combines an AI chatbot with a human support workflow. Customers can communicate with the AI through a chat interface, while support staff can take over conversations when human assistance is needed.

## How It Works

Customer → AI Chatbot → Knowledge Base → AI Response → Human Handoff

## Main Features

- Automated AI customer support
- Knowledge base search
- Conversation history
- Human handoff for complex issues
- Support ticket management
- Staff dashboard

## Main Goal

The goal of this project is to demonstrate how AI, Retrieval-Augmented Generation (RAG), APIs, databases, and human-in-the-loop workflows can be combined to build a practical customer support platform.
